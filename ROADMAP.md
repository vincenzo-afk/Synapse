# Roadmap (human-readable summary)

See `docs/15-build-roadmap.md` for the authoritative, detailed phase plan
that AI agents should follow. This file is a quick-glance summary.

- **Phase 0** — Project scaffold, tooling, PWA shell, design system tokens
- **Phase 1** — Data layer (Dexie schema for all modules) + shared engines
  (Reminder, Timer, Tracker)
- **Phase 2** — Today, Habits, Tasks, Calendar (the daily-use core loop)
- **Phase 3** — Hydration, Nutrition, Sleep, Workout
- **Phase 4** — Study, College, Projects
- **Phase 5** — Journal, Vault, Finance, Personal
- **Phase 6** — Analytics, Dashboard widgets, Settings
- **Phase 7** — Import/Export/Backup, Sensors & Browser Integration polish
- **Phase 8** — PWA hardening, offline QA, performance pass, accessibility
  pass, release
