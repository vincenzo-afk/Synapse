# Security Policy

## Supported Versions

We actively support the latest version of Synapse.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As Synapse is a local-first application, most security concerns will be related to browser-side data isolation and PWA security.

If you discover a security vulnerability, please report it by opening a private issue on GitHub or by contacting the maintainers directly if a contact method is provided.

**Do not report security vulnerabilities through public GitHub issues.**

We will investigate all legitimate reports and make every effort to quickly address the issue.
